How it works

Set up in a minute. Then forget it.

Install once, press one shortcut, walk away. That's all there is to it.

  1. PS> irm …/install.ps1 | iex
    notidle installed.
    Press Ctrl+Alt+O to turn it ON / OFF.
    Starts when you log in to Windows.
    01

    Install

    Open PowerShell (press the Windows key and type powershell), paste the command and press Enter. It starts with Windows from now on.

  2. Ctrl+Alt+O
    notidle:OFFON
    02

    Switch it on

    Press Ctrl+Alt+O (the letter O). The dot in your tray turns green. You can also left-click the dot.

  3. 60sidle
    03

    Walk away

    After 60 seconds without input it nudges the mouse, so you stay Online. Press the shortcut again when you're back.

What it does

Small, quiet and careful.

A tiny PowerShell script with a tray icon. It does one thing and stays out of your way.

1 px, then back

After 60 seconds of no input it moves the mouse 1 px right and 1 px back. The cursor ends where it started.

Never in your way

Nothing happens while you're using the PC, and nothing ever gets clicked.

Keeps the PC awake

While it's on, Windows won't go to sleep or turn the screen off.

Touches nothing else

No admin rights, no network, and it never reads or changes Discord.

Always starts off

It runs when you log in and waits in the tray. Nothing happens until you switch it on.

Free and open source

MIT licensed. Every line is on GitHub to read.

Commands

Everything, from the terminal.

Change the shortcut, the timing, or remove it all. The Node.js commands work no matter which way you installed.

PowerShell No Node.js needed

  • irm …/install.ps1 | iex

    Install or update, then start

  • irm …/uninstall.ps1 | iex

    Remove everything

Node.js npx, no global install

  • npx notidle

    Install or update, then start

  • npx notidle hotkey ctrl+shift+f9

    Change the shortcut. Modifiers: ctrl, alt, shift, win. Key: A–Z, 0–9, F1–F24.

  • npx notidle interval 120

    Idle seconds before each nudge (10–3600, default 60)

  • npx notidle start / stop

    Start or quit the background agent

  • npx notidle status

    Show what's installed and running

  • npx notidle uninstall

    Remove everything
