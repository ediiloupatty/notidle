notidle
=======

Keep your Discord status Online (green) while you're away from the PC. Toggle it with a keyboard shortcut. Windows only.


HOW IT WORKS

Discord marks you Idle when Windows reports no mouse or keyboard input for a while. While notidle is on, it checks every second how long the PC has been idle. Once that reaches 60 seconds, it moves the mouse 1 px right and 1 px back.

The cursor ends where it started and nothing gets clicked. It never does anything while you're using the PC.

While on, it also stops Windows from sleeping or turning the screen off.


WHAT IT IS

A small PowerShell script with a tray icon. It needs no admin rights, sends nothing over the network and doesn't touch Discord itself.

It installs into %LOCALAPPDATA%\notidle and adds a shortcut to your Startup folder, so it runs when you log in. It always starts OFF.


HOW TO USE

1. Open PowerShell (press the Windows key, type powershell), paste the install command and press Enter.
2. Press Ctrl+Alt+O (the letter O). The dot in your tray turns green.
3. Walk away. Press the shortcut again when you're back.

PS C:\Users\you> 
C:\Users\you>npx notidle
notidle installed.

  Press Ctrl+Alt+O to turn it ON / OFF.
  Tray icon: green = ON, gray = OFF. Left-click it to toggle too.
  Starts automatically when you log in to Windows.

  Change shortcut:  npx notidle hotkey ctrl+shift+f9
  Remove:           npx notidle uninstall

Uninstall notidle

To remove notidle and its Startup shortcut, run one of these:

irm https://raw.githubusercontent.com/ediiloupatty/notidle/main/site/uninstall.ps1 | iex
npx notidle uninstall
