notidle keeps your Discord status Online when you step away from the PC. One command to install, one shortcut to switch it on.

npx notidle

How to use

  1. Open a terminal and run npx notidle. It installs itself and starts with Windows from now on.
  2. Press Ctrl+Alt+O (the letter O). The dot in your tray turns green.
  3. Walk away. Press the shortcut again when you're back to switch it off.

What it does

  • Moves the mouse 1 px and back after 60 seconds of no input, so Windows never reports you as idle.
  • Stays out of your way. Nothing happens while you're using the PC, and nothing gets clicked.
  • Keeps the PC awake while it's on: no sleep, no screen-off.
  • Touches nothing else. No admin rights, no network, never reads or changes Discord.

Commands

npx notidleInstall or update, then start
npx notidle hotkey ctrl+shift+f9Change the shortcut
npx notidle interval 120Idle seconds before each nudge (default 60)
npx notidle start / stopStart or quit the background agent
npx notidle statusShow what's installed and running
npx notidle uninstallRemove everything
